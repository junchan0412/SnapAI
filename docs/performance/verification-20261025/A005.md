### 函数行为解释

该函数 `eligible_ids` 遍历输入列表 `rows` 中的每一行字典，筛选出符合条件的 ID 并返回一个去重后的列表。具体逻辑如下：
1.  提取每行的 `id` 字段。如果 `id` 缺失（值为 `None`）或该 `id` 已经处理过（存在于 `seen` 集合中），则跳过该行。
2.  检查该行是否满足两个条件：
    *   `active` 字段为 `True`（默认 `False`）。
    *   `score` 字段的值大于或等于参数 `minimum`（默认 10）。
3.  若同时满足上述条件，将 `id` 加入 `seen` 集合（用于后续去重）并追加到 `result` 列表中。
4.  若任一条件不满足，`id` 不会被加入 `seen` 集合，因此后续相同 `id` 的行仍有机会被评估。
