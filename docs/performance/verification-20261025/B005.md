

## 函数行为说明

该函数遍历字典列表，筛选出**有唯一 `id`**、**`active` 为 `True`** 且**`score` 不小于 `minimum`**（默认 10）的记录，返回其 `id` 列表。同一 `id` 只保留第一次满足条件的记录，`id` 为 `None` 的记录被忽略。

## 调用结果

| 调用 | 结果 |
|------|------|
| `eligible_ids(rows)` | `["a", "c"]` |
| `eligible_ids(rows, minimum=13)` | `["c"]` |
| `eligible_ids([{"id": "z", "active": True, "score": "N/A"}])` | 抛出 `TypeError`（字符串与整数比较） |

## 要点说明

1. **短路判断**：`key is None or key in seen` 中若 `key is None` 已为 `True`，则 `key in seen` 不会被求值；`row.get("active", False) and row.get("score", 0) >= minimum` 中若 `active` 为 `False`，则后面的分数比较不会被执行，从而避免对 `"N/A"` 等非法值进行数值比较，但在第三个调用中 `active` 为 `True`，短路未触发，导致 `TypeError`。

2. **可变参数是否会被修改**：函数只读取 `rows` 中的元素，不修改原列表或其内部字典；`minimum` 是整型不可变参数。因此传入的可变参数 `rows` 不会被函数修改。
