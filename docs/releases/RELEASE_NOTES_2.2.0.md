# SnapAI 2.2.0

日期：2026-11-03。

本版改善设置工作台的排序、图标与窗口行为。

- **拖动排序**：直接拖动供应商和动作卡片左侧把手；侧栏导航同样支持拖排，顺序自动保存。移除卡片右侧和底部的上移、下移按钮。
- **供应商图标**：默认根据 API 端点推断网站，读取网站声明的 favicon；可指定网站地址、使用内置符号或上传本地图片。图标库支持复用和删除，删除后恢复网站图标。
- **透明玻璃**：设置详情区、结果、快捷提问和命令面板采用透景材质；macOS 26 卡片继续使用 Liquid Glass，旧系统使用原生毛玻璃回退。
- **Dock 跟随主面板**：打开设置或引导主面板时显示 Dock 图标；关闭最后一个主面板后隐藏，菜单栏、快捷键和后台请求继续运行。最小化保留 Dock 入口。移除旧手动开关；旧 `snapai://dock/show`、`hide` 链接对应打开、关闭主面板。
- **全新图标**：重新绘制 light/dark 双图标，应用于 Dock、设置侧栏与欢迎界面，跟随系统外观切换。
- 修复开发报告中 AX 类型转换、OCR 取消测试的编译 warning，并保留原有类型和取消检查。

网站图标请求不携带 API Key 或用户 Cookie；网站可观察常规资源请求。导入图片保存在本机 Application Support 的图标库，配置仅保存引用；跨设备没有对应图片时回退网站图标。图标请求失败不影响模型请求。

发行包面向 Apple Silicon，最低系统为 macOS 14。继续使用已有稳定自签名身份及 Sparkle EdDSA 更新通道；首次安装按 [README](../../README.md) 的说明清除 quarantine 后打开。macOS 14/15 的真机材质回退、双设备 iCloud 和完整跨应用写回仍缺完整实测证据。

供应商、动作与侧栏的双向重排，以及图标库导入、复用和删除已通过本机 GUI 验收；已有逻辑、流式 runtime、窗口生命周期和网站图标获取记录。本机完整发布预检、真实 OCR、最终 App runtime、稳定代码签名、ZIP/manifest/SBOM 和 Sparkle appcast 校验均已通过；发布源码同 HEAD 的 push 和手动 CI 均通过。测试范围、状态和构建来源见 [2.2.0 验收记录](../reports/RELEASE_ACCEPTANCE_2.2.0.md)。
