# SnapAI 2.3.0

日期：2026-11-18。

本版围绕原生 macOS 工具体验重构全量界面与交互架构，重绘浅色/深色应用图标并新增多主题图标切换。

- **统一五栏主工作台**：收敛原分散的独立窗口与重复页签为「模型与服务」「动作与快捷键」「历史与会话」「通用与隐私」「权限与诊断」五大板块；全量统一简体中文界面文案，消除中英混排回退。
- **原生分组卡片设计体系**：重构设置表单行、分段组与材质层级，去除嵌套毛玻璃带来的灰暗双边框；「权限与诊断」改为延迟按需加载代码签名摘要，打开不再阻塞主线程。
- **紧凑快捷提问条**：采用无标题栏 Spotlight 风格动态高度面板，新增内联模型快速切换胶囊，精简图片附件、裁剪与本地 OCR 发送模式条。
- **内联多轮结果面板**：头部集成模型切换与双模型对照入口，对话流内联展示多轮问答与单轮分支按钮，追问框集成圆形发送按钮，移除低频手动输入摘要压缩入口与顶部空白安全区留白。
- **全新棱镜图标与多主题切换**：使用多层矢量光影重绘 4 套应用图标主题（极光棱镜、曜石钛金、翡翠灵境、暮光珊瑚），均提供独立浅色与深色版本；支持在「通用与隐私 → 应用图标」或命令面板（`⌘K`）中自由切换主题及外观策略（跟随系统 / 浅色 / 深色），实时同步 Dock 与侧栏且不改动应用签名包结构。

发行包面向 Apple Silicon，最低系统为 macOS 14。继续使用稳定自签名身份及 Sparkle EdDSA 更新通道；首次手动安装请按 [README](../../README.md) 说明执行 `xattr -cr` 清除隔离属性后打开。
