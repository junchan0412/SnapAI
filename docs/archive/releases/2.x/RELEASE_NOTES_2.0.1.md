# SnapAI 2.0.1

SnapAI 2.0.1 是一次界面一致性修复版本，统一了各窗口区域的表面配色，消除了不同区域之间的色差与接缝。功能、配置、快捷键与历史记录完全兼容 2.0.0。

## 界面一致性

- 统一结构性区域的表面配色：标题栏、工具栏、footer、窗口主体与侧栏共用同一窗口基底色。此前这些区域分别使用 `windowBackgroundColor`、`controlBackgroundColor` 与 `textBackgroundColor` 三种系统色，在浅色与深色模式下呈现出不同的接缝色差，且各窗口互不一致。
- 结果窗、快捷提问、历史记录、替换预览与命令面板统一采用同一基底，跨窗口观感一致；区域之间的层次改由分隔线与留白表达，而非背景色跳变。
- 真正需要抬升的内容（文本编辑区、输入框、卡片、代码块）继续使用带边框的内容表面，作为有意的层次强调，而非无意的色差。
- 将隐私、供应商与 Markdown 等界面中散落的硬编码颜色（`Color.green`、`Color.blue`、`Color.primary.opacity(...)`）收敛为统一的语义设计令牌，配色随浅深色模式一致适配。

## 兼容性

- 纯界面呈现调整，不涉及数据结构、请求链路、存储或快捷键行为。
- 需要 macOS 14 或更高版本，发布包为 Apple Silicon 构建。
- 继续使用原来的 bundle id、稳定签名证书与 manifest 公钥，支持应用内升级。
- 提供 ZIP、签名 manifest、签名文件与 SBOM。应用仍采用自签名分发，尚无 Apple notarization；首次安装步骤见 README。
