# SnapAI 1.6.75 迭代报告

## 问题证据

1.6.74 已完成基础视觉令牌重构,但高频路径仍有三个可见问题:

1. 截图按钮虽然显示进行中状态,发送与粘贴仍可通过键盘或其他路径触发。
2. 历史 mutation 的失败结果缺少统一反馈,用户无法判断数据是否真正写入 SQLite。
3. 结果操作按钮的命中区域和表面样式仍存在局部差异,鼠标与辅助技术体验不一致。

## 实施边界

- 在 `SnapAIUI` 中增加语义 surface、focus 和最小命中区域令牌。
- 在快捷输入、结果面板、历史窗口和操作反馈中复用令牌,保持既有 macOS 原生视觉方向。
- 让截图状态成为发送/粘贴的共同前置条件,并把历史持久化失败接入现有反馈横幅。

## 回归保护

- 逻辑兼容 runner 全绿,审计门禁通过。
- 完整 Xcode toolchain 下 `./build.sh` 成功并使用稳定本机签名。
- 未改变 provider 协议、隐私策略、历史数据格式或自动更新验证协议。
