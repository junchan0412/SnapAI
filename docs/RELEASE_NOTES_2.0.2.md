# SnapAI 2.0.2

SnapAI 2.0.2 重构了应用内更新窗口,并进一步收敛主界面的视觉噪声。功能、配置、快捷键与历史记录完全兼容 2.0.x。

## 应用内更新

- 「检查更新」由系统 `NSAlert` 弹窗改为原生更新对话框:应用图标、标题与副标题、以及一张实心圆角的发布说明卡片,直接呈现该版本的 Markdown 更新说明,与设置/详情页的卡片风格一致。
- 新增「今后自动下载并安装更新」选项与「跳过此版本」「稍后提醒」「安装更新」三个操作,主操作用品牌强调色。
- 点「安装更新」后进入紧凑的下载进度窗,按字节实时显示下载进度(如 4.1 MB / 10.1 MB),可随时取消;下载完成后进入校验与安装阶段,自动替换并重启。
- 更新窗口整体贴合统一窗口基底,无区域色差;下载、签名校验、解包与签名连续性校验逻辑保持不变。

## 界面一致性

- 删除主界面各区域之间的分割线:设置页标题栏与正文之间、AI 模型页「概览 / 供应商」与「自动路由」之间的分隔线均已移除,区域衔接改由留白表达,更干净。
- 修复供应商行排序菜单的图标异常:此前「···」省略号按钮会同时显示一个多余的下拉箭头,现已隐藏菜单指示箭头,只保留省略号。

## 兼容性

- 纯界面与更新流程呈现调整,不改变更新包的下载、校验与安装安全链路。
- 需要 macOS 14 或更高版本,发布包为 Apple Silicon 构建。
- 继续使用原来的 bundle id、稳定签名证书与 manifest 公钥,支持应用内升级。
- 提供 ZIP、签名 manifest、签名文件与 SBOM。应用仍采用自签名分发,尚无 Apple notarization;首次安装步骤见 README。
