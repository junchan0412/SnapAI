# SnapAI 2.1.0

本版接续项目审查报告第 9、10 节，完善截图输入、长文阅读、模型对照、自动化和本机会话。

## 功能与修复

- 图片默认保留原图，明确选择原图、OCR 文字或图文一起；支持选区、窗口和主屏截图、发送前像素裁剪，以及可用键盘调整的裁剪控件。识别任务取消和旧结果隔离，失败保留草稿。
- 生成与逐字展示分开，网络完成即可继续追问；可立即显示全文，完整回答不会因跳过动画标成部分结果。动效响应 Reduce Motion。
- Markdown 表格、横向代码滚动、基础代码高亮和阅读位置恢复；修复首次布局尚未挂载就定位末尾的问题。
- 任意模型别名可覆盖视觉、推理、上下文和价格元数据；双模型真正独立发起请求，分别显示耗时、错误和取消状态。
- Shortcuts 支持等待正文并返回可组合结果或结构化错误；隐私预览覆盖系统提示、历史、图片和当前问题，发送使用已确认快照。
- 统计实际 token、TTFT、API 耗时、估算费用与月预算提醒；缺失 usage 不冒充零。预算提醒不是供应商扣费硬限额。
- 本机持久会话保留全部轮次和原图；历史窗口与结果窗口可恢复，恢复不自动发请求。可从回复创建分支，手工确认摘要后压缩上下文并随时撤销；原始轮次不删除。OCR-only 的原图仅本机保留。
- 会话遵守动作历史开关、保存上限、仅元信息及高风险隐私保护；清空历史同时清除已保存会话和图片。恢复会话禁用旧目标写回。
- 写回前核对源文、选区、目标和剪贴板竞争；已知变化拒绝，无可靠锚点时要求明确确认。历史查询支持取消和先显示词法结果。

## 验证

逻辑、独立 runner、流式及 App runtime、macOS smoke、签名安装包与更新 feed 按发布预检验证。原始日志、固定模型任务和本机性能结果见 [2.1.0 验收记录](RELEASE_ACCEPTANCE_2.1.0.md)。

## 兼容性与范围

- 最低 macOS 14，沿用原自签名身份及 Sparkle 更新通道；首次安装仍需右键打开。
- 持久会话仅保存在本机，不同步 iCloud；压缩使用用户确认的摘要，不自动额外调用模型。
- 文件检索与引用按需求排除本轮；应用自动配置、分段接受改写未纳入本次已验证需求。
- 真实模型存在错误、截断和供应商失败风险；验收记录保留真实失败，不能保证每次回答可直接交付。
- macOS 14/15、120 Hz 帧预算、完整 VoiceOver 人工走查和所有外部应用控件未获完整实机验证，不作全面通过声明。
